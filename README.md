# LuckyBlockEvents200

LuckyBlockEvents200 is a Minecraft plugin that adds lucky block events to the game. It allows players to place lucky blocks that, when broken, can trigger various events such as item drops, mob spawns, or other surprises. The plugin is designed to enhance the gameplay experience by adding an element of randomness and excitement.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server to enable the plugin.

## Use

1. Join a Minecraft server with the LuckyBlockEvents200 plugin installed.
2. Use the `/luckyblock` command to place a lucky block in your inventory.
3. Place the lucky block in the world.
4. Break the lucky block to trigger a random event.
